Dataset: Anisotropic Radial Basis Functions
========

Description
========
This folder contains the data used in the paper: 
A meshless data-tailored approach to compute statistics from scattered data with adaptive radial basis functions
A preprint can be found under: https://arxiv.org/abs/2511.20449

Usage
=====
The user should execute `download_and_plot_data.py` . This downloads the dataset and unzips it. It will also plot slices of the data
This will visualize the two used datasets:

1. A turbulent boundary layer from DNS, taken from Johns Hopkins Turbulent Database https://turbulence.idies.jhu.edu/datasets/wallBoundedTurbulence/channelFlow

2. A turbulent jet from 3D PTV, taken from "A meshless and binless approach to compute statistics in 3D ensemble PTV", https://arxiv.org/abs/2403.11828
